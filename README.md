# Group 12 - 2026 IIVP Hindi Digits Classification Challenge

## Requirements
-  `uv` (checkout: [[uv-installation](https://docs.astral.sh/uv/getting-started/installation/) ])

To sync with venv and configuration:
```bash
uv sync
```
To add packages (pip-like):
```bash
uv add <package_name>
```
To execute code (automatically uses venv):
```bash
uv run main.py
```
